# SEO Principles & Beginner Fundamentals

> A practical, beginner-friendly guide to what happens after deploying a website — from discovery and crawling to indexing, ranking, and improving search visibility.

Deploying a website is only the beginning.

A website can be live, work perfectly, and still have little or no visibility in search engines.

This guide explains what happens **after deployment** and how to understand and troubleshoot the different stages of search visibility.

## 🧭 The Journey

```text
Website
   ↓
Deployment
   ↓
Discovery
   ↓
Crawling
   ↓
Indexing
   ↓
Ranking
   ↓
Search Visibility
```
